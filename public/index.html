      快速启动

      一键启动 Chrome 调试实例

      如何获取 Chrome profile 路径？

      1. 在 Chrome 地址栏输入 chrome://version 并回车
      2. 找到「个人资料路径」(Profile Path) 一行
      3. 复制该路径，例如 C:\Users\你的用户名\AppData\Local\Google\Chrome\User Data\Default
      4. 粘贴到下方文本框中，或新建一个独立目录如 C:\chrome-cdp

      ⚠️ 如果使用正在使用的 Chrome profile，需先完全关闭 Chrome 再启动调试实例，否则 CDP 端口不会生效。建议使用独立的新目录。

      ⚠️ 如果要复用已有登录态：路径填 User Data 目录（不含 \Default 后缀），Profile 目录名填对应的 Profile（如 Default 或 Profile 17）。复制时只需复制 3 样东西到新目录：Local State 文件（含解密密钥）、First Run 文件（如有）、以及你要用的 Profile 目录（如 Profile 17）。不需要复制其他 Profile 目录。缺少 Local State 会导致登录态丢失。
